Roadmap — modèle RM (S46+)

Classeur .xlsm / .xlsx, onglet AUCHAN (sections Besoin / Capa / Effectif / SLA · QE / DMT / Occupation / Absentéisme / Congés). Alimente les 3 vues de l'onglet Roadmap.

Prévision Webhelp — jour & 30 min

Classeur .xlsx : onglet 2026 (prévus mensuels par flux) + onglet Poids (poids journaliers, poids par jour de semaine et créneaux 30 min — colonne R, format 730 = 07:30). Sert à la répartition journalière et par créneau du capacitaire (onglet Roadmap).

Données DASHBOARD CAPA AUCHAN — planification & réalisation

Classeur .xlsx : feuille Planning (une ligne = agent × jour : Statut, Shift In/Out, Pause repas, HP, Total FIM), feuille Skills (compétences : HYPER/DRIVE 50/50 sur les 2 activités et les canaux MAIL/PHONE · ALL toutes activités et canaux · SAV sur PHONE · CHAT sur CHAT), feuilles EXT_Agent (heures de log réalisées), EXT_Entrant (appels : réalisés + DMT) et EXT_Email (courriels). Alimente les onglets Planification, Analyse capa et Analyse réalisé.

Chaque import est fusionné aux données en cours (même date / même activité = valeur remplacée), puis sauvegardé automatiquement dans ce navigateur (IndexedDB, repli localStorage — vos données et vos hypothèses de productivité restent en place après actualisation ou fermeture de la page, même pour de gros fichiers). « Exporter » produit le data.json à déposer dans le dépôt GitHub.
